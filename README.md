# Спутниковые антенны и интернет на даче — СПб и Ленинградская область

Одностраничный сайт для загородной аудитории 60+.

Адрес: https://spbsputnik.github.io/tv/

Репозиторий: https://github.com/spbsputnik/tv

## Что внутри

```
sputnik_spb/
├── index.html      главная страница (HTML + CSS + минимальный JS, всё в одном файле)
├── .nojekyll       отключает Jekyll на GitHub Pages
└── assets/
    └── favicon.svg значок сайта
```

Всё самодостаточно: ни одного внешнего запроса, шрифтов и библиотек. Страница работает без интернета.

Иконки — инлайн-SVG-спрайт в начале `index.html` (`<symbol id="i-...">` + `<use href="#i-...">`), отдельных файлов не требуют.

## Принципы оформления

- Одна колонка, ширина не больше 1100 px
- Основной текст 20 px, межстрочный интервал 1.7, не больше 60 знаков в строке
- Кнопки от 64 px, крупные чекбоксы, никаких выпадающих списков
- Без каруселей, всплывающих окон, тёмной темы и анимаций
- Поддержка `prefers-reduced-motion`

### Цветовая система (CSS-переменные в `:root`)

| Переменная | Значение | Назначение |
|---|---|---|
| `--grad-brand` | `#1B5E3F → #31945F` | кнопки, иконки, шапка таблицы |
| `--grad-hero` | `#0A1F16 → #123B28 → #1D6644` | первый экран, блок обещаний, подвал |
| `--grad-warm` | `#C97A20 → #A85A18` | акцентные иконки, цены |
| `--grad-mesh` | мягкий зелёно-бежевый | заглушки фотографий |
| `--ink` / `--muted` | `#0E1F17` / `#616D66` | текст |

Тёмные блоки — только с белым текстом. Любой элемент внутри `.hero` обязан задавать `color` явно, иначе он наследует белый и становится невидимым (такой баг был с `.choice` и `.opt`).

## Что нужно заменить перед запуском

1. Телефон `8 (812) 000-00-00` и все ссылки `tel:+78120000000` — настоящий номер
2. Название компании
3. Адрес офиса в подвале
4. Фото в блоке «Наши работы» — три заглушки `.work .ph`
5. Цены в таблице и в карточках услуг
6. Отзывы в блоке «Что говорят клиенты»
7. Названия районов в блоке «Куда выезжаем», если выезд ограничен

## Деплой

```powershell
git -C C:\OPEN_CODE\Misha_Antenni\sputnik_spb push origin main
```

GitHub Pages публикует содержимое корня `main`. Отдельный workflow не нужен.

**Важно:** Pages включается вручную один раз —
**Settings → Pages → Source → Deploy from a branch → `main` → `/(root)`** → Save.

Автодеплой через `actions/configure-pages` с `enablement: true` не помогает: воркфлоу падает на шаге `Setup Pages`, пока Pages не включён. Проверено 2026-10-02.
