# Спутниковые антенны и интернет на даче — СПб и Ленинградская область

Одностраничный сайт для загородной аудитории 60+.

Адрес: https://sputnikspb.github.io/tv/

## Что внутри

```
sputnik_spb/
├── index.html              главная страница
├── .nojekyll               отключает Jekyll на GitHub Pages
└── assets/
    ├── scene-dacha.svg     главная иллюстрация: дом, антенна, яблоня, трава, цветы
    ├── dish.svg            спутниковая антенна на доме
    ├── apple-tree.svg      яблоня с яблоками
    ├── grass-strip.svg     полоска травы с цветами (разделитель)
    ├── flowers-row.svg     цветочная полоса
    └── favicon.svg         значок сайта
```

Всё самодостаточно: ни одного внешнего запроса, шрифтов и библиотек. Страница работает без интернета.

## Принципы оформления

- Одна колонка, ширина не больше 1100 px
- Основной текст 20 px, межстрочный интервал 1.7, не больше 60 знаков в строке
- Тёплая загородная палитра: фон `#FAF7F0`, акцент `#2F6B3C` (контраст 7.8:1), цены `#C87A2B`
- Кнопки от 64 px, крупные чекбоксы, никаких выпадающих списков
- Без каруселей, всплывающих окон, тёмной темы и анимаций
- Открытые цены, фиксированная цена до выезда, оплата после монтажа

## Что нужно заменить перед запуском

1. Телефон `8 (812) 000-00-00` и ссылку `tel:+78120000000` — настоящий номер
2. Название компании в шапке и в подвале
3. Адрес офиса в подвале
4. Фото в блоке «Наши работы» — заменить заглушки на реальные фотографии
5. Цены в таблице и в карточках услуг — на свои
6. Отзывы в блоке «Что говорят клиенты» — на настоящие

## Деплой

Репозиторий называется `tv`, поэтому адрес получается `sputnikspb.github.io/tv/`.

После первого пуша в GitHub: **Settings → Pages → Source → Deploy from a branch → `main` → `/(root)`**.
